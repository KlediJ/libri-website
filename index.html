Why Libri

The point of Libri is not novelty. It is control. It helps you organize imported financial data without sending it away.

Local-first

Your data stays with you

Libri runs as a Windows desktop app and stores your data locally. No account signup, no mandatory sync, no subscription wall.

Practical cleanup

Built for real imported transaction data

Import CSV or Excel files, review payees and categories, resolve transfers, and use “apply to similar” to speed up repetitive cleanup.

Useful payoff

Better inputs produce better views

Once the ledger is cleaned up, Libri gives you a clear dashboard and a monthly spending flow that helps you see where your money went.

How it works

Libri is strongest when you treat it as a practical review workflow instead of an “AI magic” black box.

Recommended setup

Start clean

  • Create your accounts first and label them clearly.
  • If you track multiple accounts, separate names make transfers easier to review.
  • Import transactions from CSV or Excel exports.
  • Use Ledger as the main place to review and edit transactions.
